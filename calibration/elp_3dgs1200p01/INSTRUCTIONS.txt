ELP 3DGS1200P01 STEREO CALIBRATION - INSTRUCTIONS
================================================
Camera : ELP USB3DGS1200P01 (OG02B10 global shutter, synchronized dual lens)
USB    : /dev/video0, ONE side-by-side MJPG frame 3200x1200
         = left 1600x1200 | right 1600x1200
Rule   : calibrate at the resolution you will run at.
This screen: 2560x1440, 600mm wide => 150px squares ~= 35.16mm (ALWAYS measure).

Files in this folder
--------------------
  screen_calibrate.py            RECOMMENDED: fullscreen board + top-right
                                 live preview in ONE window (no focus issues)
  capture_stereo.py              fallback: capture only, small window
  show_checkerboard_screen.py    fallback: board only, windowed
  stereo_calibrate.py            calibrate pairs/ -> calib/
  stereo_depth_demo.py           live rectified + SGBM depth test
  generate_checkerboard.py       regenerates checkerboard_9x6_25mm.png/.pdf
  checkerboard_9x6_25mm.pdf/.png print version (best metric accuracy)

QUICK START (recommended, single monitor)
-----------------------------------------
1) Run the combined app:
     python3 screen_calibrate.py
   Board is fullscreen. Live preview is pinned top-right INSIDE the same
   image (outside the squares, never covered). One key handler, so no
   terminal clicking needed.

2) Capture ~25 pairs (see technique below). Keys (window focused):
     SPACE = save pair if board found in BOTH eyes
     f     = force-save even without detection
     d     = toggle detection on/off (off = max fps)
     p     = toggle preview PiP on/off (for a clean board shot)
     q/ESC = quit
   Preview PiP shows rainbow corner lines when the board is found in an eye
   (may lag 1-2 frames: detection runs every --detect-every frames).
   Green L:OK R:OK = good to save with SPACE.
   Saves full-res to pairs/left/leftNNN.png, pairs/right/rightNNN.png,
   pairs/full/fullNNN.jpg regardless of preview size.

3) Measure displayed squares with a ruler (average 5, e.g. 35.2mm), then:
     python3 stereo_calibrate.py --square 0.0352 --out calib

4) Check calib/results.txt + calib/rectified_example.png, then test depth:
     python3 stereo_depth_demo.py --calib calib/stereo_calibration.npz

screen_calibrate.py - RUN ARGUMENTS
-----------------------------------
  Board:
    --cols 9 --rows 6            inner corners (default 9x6)
    --sq-px 150                  square size, screen pixels (default 150)
    --screen-w 2560 --screen-h 1440
                                 MUST match native res or squares blur/scale
    --top-bar 300                reserved top strip for preview (default 300)
    --pip-width 640              preview width px, height auto 8:3 (640->640x240)
    --no-pip                     start with preview hidden
  Camera:
    --device 0                   /dev/video0
    --width 3200 --height 1200   MUST match runtime resolution
    --fps 30                     request; actual ~12fps at 3200x1200 (USB2/limit)
    --out pairs                  output dir (left/ right/ full/ subdirs)
    --detect-every 4             detection every Nth frame (speed vs feedback)
    --detect-scale 0.5           detection downscale (0.5 = 800x600/eye)
    --no-detect                  start with detection off (max fps, save with f)

  Examples:
    python3 screen_calibrate.py
    python3 screen_calibrate.py --sq-px 150 --pip-width 640 --out pairs
    python3 screen_calibrate.py --detect-every 10 --detect-scale 0.4
    python3 screen_calibrate.py --no-detect            # fastest, save with f
    python3 screen_calibrate.py --width 2560 --height 720   # ONLY if you run at 720p

stereo_calibrate.py - RUN ARGUMENTS
-----------------------------------
    --pairs pairs      input dir (left/ right/ or full/ side-by-side fallback)
    --cols 9 --rows 6  must match board
    --square 0.025     square size in METERS (screen: measured, e.g. 0.0352)
    --out calib        output dir
    --min-pairs 10     abort if fewer good pairs
  Examples:
    python3 stereo_calibrate.py --square 0.0352 --out calib     # screen
    python3 stereo_calibrate.py --square 0.025 --out calib      # print
    python3 stereo_calibrate.py --pairs pairs --cols 9 --rows 6 --square 0.0352
  Outputs (calib/):
    stereo_calibration.npz, calibration_opencv.yaml,
    left.yaml / right.yaml (ROS camera_info),
    results.txt (rms, baseline, f), rectified_example.png, q_matrix.txt
  Pass criteria: stereo rms < 0.5px, mean |dy| < 1px.
  rectified_example.png green lines must be horizontal and aligned L-R.
  Depth: Z = f * baseline / disparity (see stereo_depth_demo.py).

stereo_depth_demo.py - RUN ARGUMENTS
------------------------------------
    --calib calib/stereo_calibration.npz --device 0
  Keys: q=quit  s=save snapshot (depth_snapshot.png)

PRINT OPTION (best metric accuracy)
-----------------------------------
1) Print checkerboard_9x6_25mm.pdf at 100% / Actual size (no fit-to-page).
   Verify squares = 25mm. Glue flat on cardboard/box.
2) python3 screen_calibrate.py --sq-px 150   (ignore screen board, point at print)
   or: python3 capture_stereo.py
3) python3 stereo_calibrate.py --square 0.025 --out calib

CAPTURE TECHNIQUE (~25 pairs minimum)
-------------------------------------
  - Both eyes must see the FULL board sharp (SPACE needs L:OK R:OK).
  - Vary: center/edges/corners of both views, tilt +-30deg,
    yaw/pitch/roll, distance 0.5-2m (screen) or 0.5-3m (print).
  - Flat board, good light, no motion blur, no glare (dim room, max brightness
    for screen). Hold still ~0.5s before SPACE (12fps + exposure lag).
  - If the camera also sees the preview PiP on screen: fine, detection
    ignores it. For a pixel-clean shot press p to hide, save, p to restore.

TROUBLESHOOTING
---------------
  Slow preview (~1 frame/7s in v1): v1 ran full-res detection both eyes every
    frame (~1.2s/frame). Now: half-res every 4th frame + FAST_CHECK (~6.5fps).
    Still slow? --detect-every 10 --detect-scale 0.4, or --no-detect + save w/ f.
  ~12fps max at 3200x1200 here: normal (USB2/exposure). Plenty for stills.
    Laggy motion? More light (auto-exposure), USB3 port, close browsers,
    unplug other USB devices.
  SPACE rejected: board not in BOTH eyes. Reframe, clean screen, less tilt,
    or press f to force (calibrator will drop bad ones, but get 25+ good).
  Wrong scale/depth: you passed wrong --square. Re-measure display, average 5.
  Moire/shimmer on screen: step back to 1-2m, slight angle change, focus.
